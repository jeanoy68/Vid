🎓 five together · educational demo

same live stream · five embeds · no autoplay · learn the API
What this demo teaches:
  • Embedding: each card hosts a YouTube IFrame API player via new YT.Player().
  • No autoplay: autoplay: 0 — the user must press play. This respects browser autoplay policies.
  • Programmatic control: the toolbar calls playVideo(), pauseVideo(), unMute(), and seekTo() on all players.
  • Responsive CSS Grid: 5 → 3 → 2 → 1 columns as the viewport shrinks.
  • View counting (important): YouTube counts a view per real viewer/session, not per iframe. Five iframes on one device ≠ five views. Embedding many copies is a layout/API exercise, not a way to inflate analytics.
  • Terms of Service: artificially generating views violates YouTube's ToS and can get a channel penalized. Keep learning honest.
